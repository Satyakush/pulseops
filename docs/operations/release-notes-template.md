# Release Notes Template

Use this structure for future PulseOps releases.

## Added
New user-visible or operational capabilities.

## Changed
Behavior or configuration changes that affect existing consumers.

## Fixed
Defects corrected in the release.

## Security
Authentication, authorization, validation, dependency, or secret-handling changes.

## Operations
Health, observability, deployment, migration, and rollback considerations.

Every release should state whether any configuration or data migration is required.
